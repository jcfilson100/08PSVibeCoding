Bug - Search not working

## The recommendation

**Decision:** ☐ Go  ☑ Iterate  ☐ Kill

_The evidence that justifies the call:_

Fix Search and Filter on Active Deals. Highest impact, lowest cost. These are table-stakes interactions on a screen your feedback says people actually tried to use. Right now the filter checkboxes update local state but don't filter the list, and the search input is decorative — wire both to the deal query. Every other improvement is wasted if the first thing a user touches is broken.
